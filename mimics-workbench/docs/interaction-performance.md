# 实时标注性能优化

性能阶段完成后，标注内核由仓库根目录的 workbench-kernels.lock.json 固化。
后续协同及账号接入须通过 scripts/verify-workbench-kernels.mjs，不能改写
这些文件和 Workbench 中现有工具操作函数。

## 原因与修改

- 原渲染器在每笔预览更新时，三个视图都逐像素读取响应式 props、重新映射
  灰度并分配画布缓冲。新合成器缓存浮点灰度切片，循环外读取参数，按笔画的
  体素包围盒重绘；鼠标光标移动、无关切片不重复计算图像。
- 保留原始颜色混合顺序、独立 Mask 重叠、临时选区、阈值预览、显示方向和
  最终 Uint8ClampedArray 舍入。测试逐字节对照旧实现。
- 显示统计在暂停绘制后分帧完成，保持原来的统计运算顺序。界面以
  aria-busy/data-mask-statistics-pending 标记未完成统计，避免整卷同步扫描。
- 笔画草稿是有效二值 Mask 的克隆，写入值仅为 0/1。落笔与扫描覆盖逻辑、
  一笔一事务、取消回滚、撤销与重做保持；抬笔不再次扫描整卷验证同一事实。
  对外通用 replaceMask 仍保留完整输入检查。
- MPR 只更新改变的 Mask，保留常驻 CT；大数组分块复制、异步提交。源版本、
  owner 序号与 epoch 一同隔离旧请求，未发布的副本不能被后续请求误复用。
  相同切面在更新期间保留最后一帧，新切面或新影像仍清除过期画面。

Edge，1600×1050，512×512×768 合成 CT，同一 60 帧输入轨迹。单位毫秒。

原始三视图同轨迹绘制均为 7,988 体素，擦除后均为 0；MPR 对应轨迹绘制
7,235 体素，擦除后为 0。MPR 与原始切片采用各自既有写回策略，不混为同一种算法。
819 项测试、类型检查和构建通过；包含三轴图像合成逐字节对照、精确统计对照、
MPR 源/Mask 更新、异步副本淘汰、取消、实际 Worker 采样及原有工具回归。

性能脚本为 tests/brush-performance-browser.mjs；从本目录运行，参数依次为
结果名称、离线页面文件路径、可选 mpr。PERF_NIFTI 指定练习 NIfTI，
PLAYWRIGHT_MODULE 可指定本机 Playwright 模块路径。结果只写入忽略的 artifacts。

本阶段不包含账号和协同适配的完成声明，接入完成后须另做双客户端验证。
