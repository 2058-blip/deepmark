# 三维重建内存优化（2026-11-05，本地修改）

适用于 codex/mimics-workbench-20261105 的独立工作台。本次保留原始影像、
Mask 与完整重建精度，没有默认降低采样分辨率，也没有自动减面。

## 修改

- 表面显示直接上传共享顶点、法线和索引，使用 drawElements。不再将每个
  三角形展开为重复顶点；坐标原点通过 uniform 传递。
- 线框仅在开启“网格边”时建立，关闭立即释放。隐藏、删除模型及卸载视图时
  释放 GPU 缓冲；颜色、透明度和无关修订不再重复上传未变化的几何。
- 首次显示不建立点击拾取的 BVH；实际拾取时再建立，缓存按几何数组识别。
- Marching Cubes 采用双精度坐标和整数索引构建缓冲，最终按原有方式转换
  Float32。边缓存仅保留相邻层，使用数字键；非表面立方体不分配角点对象。
- 法线方向传播和完整网格统计改用紧凑排序、邻接和关联数组，避免为每条边、
  每个顶点长期保留字符串、对象、Map 和 Set。
- Worker 直接转移结果缓冲，避免回传整份网格复制。常驻源影像明确排除，
  后续计算仍可使用。当前模型的统计按不可变几何数组缓存。
- 既有撤销预算、本地工程保存和原始影像单次持久化逻辑保留。

## 验证

- 802 项测试、类型检查和生产构建通过。新增 GPU 上传、按需线框、分配失败
  清理、WebGL 1 索引范围、Worker 转移和常驻影像保护测试。
- 独立进程：同一 425,984 三角形、4,096 个连通分量的合成模型，生成和统计
  的峰值 RSS 由 621.30 MiB 降至 138.98 MiB。顶点、索引、法线的合并
  SHA-256 均为 044ff69d21834328a01d35ad12a8fa8dbb05df48339df6d6eedcb01f8233f971；
  面积、体积、闭合与分量结果一致。此项不是整浏览器内存测量。
- 实际 Edge 文件模式：512×512×395，0.60/0.60/0.70 mm 合成影像，
  3,264,600 体素 Mask，Optimal 重建得到 2,193,408 个三角形，开放边和
  非流形边均为 0。计算、显示、自动保存、改色、线框切换、隐藏与重新显示
  通过，无页面异常或网络请求。
- 浏览器测试进程族采样的峰值私有提交内存为 2,400.42 MiB（约 2.34 GiB）。
  表面 GPU 缓冲为 52,641,888 字节（约 50.20 MiB）；开启线框增加
  52,641,792 字节，关闭线框及隐藏模型后对应缓冲均确认释放。

日志和截图位于 git 忽略的 artifacts/memory-*。合成影像与真实 CT 的复杂度
不同；测试不能保证任意同尺寸影像具有相同峰值或耗时。面数、同时保留的
Mask/Part、浏览器及 GPU 仍影响内存。显卡分配失败时保留工程数据并显示错误，
清理部分分配的缓冲。无 32 位索引扩展的旧 WebGL 1 设备会提示使用 WebGL 2。

## 仍然超限时

在 Calculate 3D 选择 Custom → Options，将 X/Y/Z step 从 1 调到 2，
先一次计算一个 Mask。这会降低输出表面的采样精度，需要用户明确选择，
不会改变原始 CT 或 Mask。关闭网格边、隐藏不用的 Part 可减少显示开销。
