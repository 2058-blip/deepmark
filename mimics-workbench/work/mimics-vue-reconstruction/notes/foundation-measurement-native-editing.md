## Area 模块

用户在同一切片逐点描轮廓，双击或Enter闭合。右击已存在的控制点打开Add Point / Remove Point菜单；未命中点时仍可右拖平移视图。Add在所选点与下一点之间插入中点，随后可拖到需要位置；Remove至少保留三个点。中点及三点下限是应用选择，原帮助没有给出插入位置或退化政策。

菜单与拖动调用同一个批量几何更新入口，始终保存世界毫米坐标和切片平面。只允许image-only Area改变点数；包括旧`partId`和新逐点Part来源在内的附着Area不能通过增删点丢弃来源。纯图像的`pointPartIds`随点数增删，保持全null及精确长度。名称、颜色、显隐和标签偏移保持原值。

拖动时几何及面积/周长/等效直径/质心/质心弦指标只读预览，标明尚未提交；松开后一次事务，Undo恢复整组点和来源。自交、非共面、零面积等无效候选可以显示原因，但不能覆盖既有有效对象；新建无效轮廓也不能写入工程。MPR仍是单独未完成模块，当前原IJK切片的仿射物理显示不能称为任意重采样MPR。

## Ellipse 模块

保存结构继续是三个world点，专用UI手柄是派生量，不向`points`附加中心或反向轴端。令`c=(p0+p1)/2`，`u=normalize(p1-p0)`，`a=|p1-p0|/2`；把`p2-c`去掉u分量后得到`b*v`，`n=u×v`。图中的四轴端点是`c±a*u`与`c±b*v`。因此例`p0=(-2,0),p1=(2,0),p2=(1,1)`的短轴端显示在`(0,1)`，不会把原始参数点误画成轴端。

两条存储轴保留原顺序，显示D1/D2仍由数值核按长短排序。轴角色改变不改变既有来源数组顺序，也不把截图中的D1/D2编号冲突当作已解决的原版数值等价。

| 操作 | 数据处理与提交 |
|---|---|
| 四轴端调整 | 目标点投影到相应轴，保持中心和方向，正负两端对称调整；轴不得为零 |
| 中心移动 | 位移投影到冻结的椭圆平面，三点整体平移，保持轴长和方向 |
| 四角旋转 | 角标位于轴向外接框四角；在冻结平面用绕n的有向角旋转三点，保持中心和轴长 |
| 标签拖放 | 只改`labelOffset`，不改三点、面积或来源 |
| 无移动点击 | 不因将旧off-axis参数标准化而新增事务；需真实移动才提交 |

ImageViewport先在world中运算，再通过完整affine和物理视口投影，支持各向异性及shear。PartViewport用相机射线与冻结椭圆平面求交，整体变换不分别snap三个点到不同Part曲面，避免刚性变换被弯曲。该工作平面政策是明确独立实现；逐点来源保留作为历史关联，不声称变换后的每个点仍是当前网格的ray-hit。

Image创建阶段在第一点后显示暂定椭圆和变量，第二点固定后鼠标定义短轴，第三次点击确认；初阶段半短轴取a/2及最终点击方式是应用约定。三维创建也已接入：前两点实际拾取Part，第二点后冻结包含轴且尽量朝向相机的物理平面；后续旋转、缩放或适配视图不会重建该平面。鼠标射线交平面定义第三点并预览全部七项指标，第三点击才一次提交。该点的来源记录为null，不伪称为某个Part的拾取结果；平行视线、零短轴或重复长轴端不给出有效确认。Escape保留对主控制器的取消传播，同token的重复点击本地与控制器双重拒绝。

## 标签与预览模块

`MeasurementObject.labelOffset?:Vec3`是相对几何标签锚点的世界毫米向量。椭圆锚点为中心，Area为面积质心；旧无字段对象保留默认标签布局。该字段仅用于非annotation测量，严格验证为稠密、无额外属性的普通三有限数数组。ZIP、history、复制与Properties草稿深拷，表单不能通过metadata patch覆写几何字段。曲面路径重算也保留旧名称、颜色、显隐及标签偏移，不再每次重置用户属性。

`previewMeasurementGeometry`保留临时点的独立副本，更新图中数字与选中详情，不写raw对象、Mask、Part、history或dirty。实际Worker导出工程只包含已提交几何。无效几何预览返回reason，提交再校验；preview和release都验证切片平面，避免错误片上的候选被当作有效结果显示。Density沿用其原生“松开才更新统计”的流程，不套用此即时几何预览。

所有事件冻结volume/revision/plane及对象来源，换对象、换工程、busy、取消或失捕获时丢弃。三维创建另有`measurementDraftToken`，因为重建同样的前两点不一定改变工程revision；取消并重新开始后，即使volume、revision和坐标都相同，旧确认事件仍被拒绝。
