## 证据与完成等级

- D：随软件本地帮助直接记载的输入、步骤、参数和输出。
- B：二进制符号/反编译直接支持的特定入口、接口和事务路径；出现名字不等于恢复数值内核。
- I：为同类行为设计的独立算法，须写明边界、数值规则和误差，不能改写成“恢复的原版算法”。

每项状态可用 `not_started / in_progress / implemented_unverified / partially_verified / verified_independent / verified_against_original / blocked`，另以 `partial` 表示整体仅部分覆盖、`implemented_independent` 表示有独立内核、`verified_independent_kernel` 表示仅所列夹具通过。当前没有任何项标为 complete 或 verified_against_original。完整通过必须至少具备：可运行后端、全部要求的 UI 步骤、非平凡合成案例、失败/退化案例、保存恢复及下游链路、格式回读和可复查的 UI 证据。`verified_against_original` 额外需要有明确原版 oracle、版本/参数/输入相同的对比和误差标准。禁止用界面按钮数量、模块函数存在或截图可见来代替这些条件。

## 必须共同通过的链路

1. 导入合成体数据，检查三个正交视图和斜切 MPR 的物理长宽比、方向、十字线和世界坐标。用旋转、非等距及剪切仿射测试，测量不能使用屏幕像素长度冒充毫米。
2. 在同一体素创建重叠 mask；分别调整阈值、画笔、布尔、可见性和颜色，验证另一 mask 成员不被覆盖。区域生长的 copy/cut 源修改必须遵守 Leave Original。
3. 对有 Apply 的工具拖动预览后 Cancel，源对象逐字节不变；Apply 仅一条完整事务；Undo/Redo 包含源/目标、对象创建/删除、测量及依赖状态。对文档明确“单击即写入”的工具按相应即时事务验证。
4. 从非平凡 mask 计算模型，在世界毫米坐标叠合，记录 sourceMaskId/sourceRevision。编辑 mask 后旧 part 不得误称自动最新；重建需明确失效/更新政策。
5. 在 2D 与 3D 建立距离、角度、直径、椭圆、多边形、密度和文字对象；端点拖动有即时反馈，完成/取消清晰，Locate、隐藏、重命名、编辑和删除可验证。
6. 保存项目，关闭后恢复，验证原始数据、仿射、独立 mask、part、测量/文字锚点与样式、分支/地标、相位、显示状态和引用关系；比较二进制内容或结构化值，不只比较截图。
7. 对实际提供的每种三维格式导出，再用独立解析器读回坐标、拓扑、单位/法向。STL 不自动保存颜色或文字，应明确每个导出对象和语义。IGES、FEA 不能用改后缀的 STL 代替。
8. 对大任务启动、取消，再切换项目或编辑源 mask；旧 job 在后面完成也不能写入新项目/新版本。验证 token、对象 ID、revision 和 worker buffer 生命周期，导入失败或取消不破坏当前项目。
9. 在定量统计中更改窗宽窗位、MONOCHROME1 或 mask 颜色，HU/GV 的均值/标准差保持不变；修改 ROI 或切片会重新采样。分别呈现离散采样面积与几何面积的定义。
10. 4D、心血管、肺叶、中心线、X-ray、FEA 等高级工具按其真实数据与步骤验证；没有算法时保留未完成。通用阈值、生长或静态三维模型不能充当其完成证据。

## 格式覆盖缺口

离线传统单帧未压缩 CT/MR 可以独立实现并用合成文件验证。压缩解码、Enhanced 多帧/4D、Modality LUT/RWVM/PixelPadding、色彩与浮点 PixelData 是额外范围；拒绝不受支持输入是正确失败行为，并不完成其格式支持。NIfTI 4D 与多通道也必须有显式时间/通道模型，禁止静默取第一帧。

患者数据不作为开发夹具；本次测试仅生成合成内存数据。原目标样本保持只读，不执行，不改变许可证。错误消息和验收记录不得混入真实患者人口资料。
