# 任意物理切面画笔：实现、操作与审核

日期：2026-11-05。此检查点为 **606/606 全量测试通过、Vue 类型检查与生产构建通过**，输出 `index-Q3i0YVh4.js`。这是独立实现的数学、控制器、Worker和SFC验证，不是原版算法等价或新版浏览器验收。

## 用户操作

1. 打开任意平面MPR，在活动且可见的Mask上选择绘制、擦除或局部阈值。三幅MPR保持打开，蓝轴编辑退出，白色定位仍独立。
2. 设置毫米宽高、联动与椭圆/矩形；按住左键连续画，抬起提交一次可撤销的修改。轨迹包含聚合事件和最终抬起点；离开再进入图像不跨空白连线。
3. Ctrl左拖调整宽高；Shift单击临时定位。蓝轴编辑模式下Ctrl优先控制蓝轴。切片/平面、工具、活动Mask、尺寸、有效阈值、工程或鼠标捕获上下文变化取消整笔，源Mask不被部分写入。
4. 局部阈值只对触及的源体素按原始灰度判定，范围内加入、范围外移除；窗宽窗位、显示插值、输出采样密度不改变其灰度判定，也不修改Mask保存阈值。

MPR中的Lasso、Flood-fill、LiveWire、多片选择/复制/插值仍未整合；这些工具继续使用原始切片路径，不属于本检查点完成范围。

## 明确采用的独立物理策略

`mprBrush.ts`在完整仿射定义的源网格中求候选，不把显示重采样像素当作可直接写回的源体素。平面单位法线为n，三个源体素物理列向量为c_i，采用闭薄层：`abs(n·(voxelCenter-origin)) <= sum(abs(n·c_i))/2`。平面穿过正交源切片中心时退化为一层；恰在半层边界时包括两层接触体素。这是应用定义，尚未恢复Mimics的任意RP写回内核。

椭圆/矩形按完整连续线段扫掠，支持各向异性、旋转、剪切、反射，裁剪到当前MPR物理FOV。逆仿射局部包围盒限制扫描；每段最多100万次访问，整笔最多800万次。超过预算或分配失败丢弃整笔预览。按源索引分页去重，每个触及体素每笔只判定一次。

预览使用活动Mask的私有副本；原灰度、重叠的其他Mask、Part和历史测量保持原值。显示映射缓存仅随输出尺寸分配，不向共享重采样Worker反复发送整卷预览。无变化不产生历史；有变化只在结束后替换活动Mask一次。

## 迟到事件与事务

三幅MPR共享递增安全整数strokeId，每笔冻结Mask、Volume对象、工程版本、MPR姿态版本及物理平面。Begin通过已接纳ID高水位拒绝重放；旧的合法Stroke/End事件忽略，缺失或损坏的当前Stroke/End取消整笔。取消事件同样携带完整冻结上下文：只有完全匹配本笔才清预览，旧或不完整的Cancel不能清掉新笔画。显式全局Cancel仍可主动取消当前工作。

真实历史提交分配失败的反例验证：预览清除，已提交源、dirty及原Redo分支保持不变。切换上下文再切回、取消再以相同平面重开均不能复用旧事件提交。
