# 本机双人协作验收

以下示例使用 <http://localhost:8794/>。按实际 `PORT` 配置替换端口；这个地址只供运行服务的这台电脑使用。仓库不附带真实 CT、患者资料或测试账号。

## 准备两个独立登录环境

1. A 使用当前 Edge 普通窗口，B 使用 Edge InPrivate 无痕窗口，或另一个浏览器。两个普通标签页会共享登录状态，不能用它们模拟两个不同账号。
2. 两边打开完全相同的地址，分别登录两个不同的“干活”账号。B 没有账号时先注册，角色选择“干活”。
3. A 返回工作台，在“我的干活组”复制邀请码。B 在“加入小组”输入这个邀请码，加入 A 已有的小组。
4. 两人都打开列表里同一个已认领的任务（本地验收示例名为“肺部 CT · 界面验收”），点击“进入协同标注”。使用同一个任务，而不是各自重新上传一份同名影像。测试时保持任务为“进行中”。

如果从零准备任务，需要一个“派活”账号上传测试 CT，由 A 的小组组长认领一次；B 加入同组后即可进入。

## 逐项验证

| 操作 | 应看到的结果 |
| --- | --- |
| 两边进入同一工程；若影像已最大化，先按 Esc 恢复布局 | “当前在线”显示两人的名字，自己的名字旁有“我” |
| B 新增一个“B 测试”标签 | A 无需刷新就能看到新标签；创建者是 B；最近操作的执行者也是 B |
| A、B 选择同一切面和切片，各用自己的测试标签，在人体内部的不同位置用画笔画一小块 | 对方无需刷新就能看到；修订号增加；操作记录分别显示两位执行者 |
| 在已有标注处悬停片刻 | 标注来源显示实际作者；它与“标签创建者”是两种信息 |
| A、B 在同一区域提交不同标注 | 保留并列意见，可从“协作详情”查看和定位；其他人的标注不能被自己的橡皮直接清空 |
| 两边都显示“已同步”后刷新、重新进入同一工程 | 标注与标签仍在，创建者与操作记录仍保留 |
| B 返回任务列表或关闭工程页面 | A 的在线人数降为 1；B 的已同步成果仍保留 |

先用新增测试标签和小范围画笔完成前几项，再测试同一区域的并列意见。无需改动原有标注。

## 跨电脑

两台电脑需要访问同一台后端服务及同一份数据库；各自的 `localhost` 指向各自的电脑，无法把它们连接起来。当前实例监听本机回环地址。如需跨电脑测试，应另行配置共同可访问的服务地址、网络和 HTTPS，再让双方打开同一个地址。登录需要安全上下文；单纯把地址改为局域网 HTTP 可能无法正常登录。
