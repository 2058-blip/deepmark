# 浅色工作台与团队平台整合

本分支以团队 `d0a4485` 为基础，将浅色界面、病例表格和影像浏览改进接入新版登录、角色工作台与标注流程。前端改动与在线成员、标签创建者所需的配套 Java 接口分别提交；完整功能需要同一分支的前后端配合运行。

## 保留与接入

- 视觉：浅色配色、按钮、分区编号、病例列筛选及排序。
- 入口：使用新版 `AuthView` 登录和 `ConsoleView` 角色工作台；病例表格由 Console 提供真实任务数据。
- 标注：保留新版缩放、外围空气过滤、作者提示、协同增量、只读与作者权限。
- `CaseList.vue` 只负责展示；上传、组队、认领、完成和导出的权限判断仍由新版 Console 与 Java 后端负责。
- `public/cases.json` 仅补充可选展示资料，不能决定任务状态或访问权限。

## 工作台设计与操作

工作台采用柔和配色、分区编号和轻量面板。影像区域保留深色背景。

- 默认采用“一张主视图＋两个辅助切面”布局，可切换为三列布局。
- 每个切面右上角均有最大化／恢复按钮；双击切面标题或选中切面后按空格可切换单视图最大化，Esc 恢复原多视图布局。切换时保持各切面的切片、缩放、平移和标注状态，画布双击不负责切换布局。
- 最大化时影像铺满左侧工具栏以外的整页区域，顶部导航、协作栏与底部信息栏收起，切面标题、恢复按钮和翻层控件以浮层保留；恢复后原界面和协作信息重新显示。错误提示与退出对话框不因最大化而失效。
- 标签卡片不参与纵向压缩，使用自适应高度、较大的内边距与卡片间距；标签名和创建者均允许自然换行，长内容撑高当前卡片，多标签通过列表滚动查看。单击或双击名称均只选中标签，只有小铅笔按钮进入改名。编辑态使用与展示态同列宽的多行输入框，文字自动换行，边框随内容增加或缩回，创建者保持在编辑框下方。Enter／失焦提交，Esc 取消；视觉换行不改变名称数据，粘贴的实际换行在提交时规范为空格，中文输入法组词确认不会提前提交。
- 保留画笔、橡皮擦、阈值和灰度分区。先选择标签，再用左键执行当前工具；普通画笔编辑当前切片，阈值应用于整套影像。
- 窗宽窗位可手动输入，也可选择肺窗（窗位 -600、窗宽 1500）、软组织（40、400）、骨窗（400、1800）和全范围预设。
- 协作栏常显当前工程的在线成员（依据认证 WebSocket 连接、同一用户多标签去重）、最近操作的执行者、动作与时间；详细历史另用“查看此版本”按钮，避免误入只读回放。断线后不把缓存成员显示为在线。
- 标签行单独显示创建者，新增标签的创建者和时间由服务器记录并随快照、增量及导出保存；修改标签名或颜色不改变创建者。旧数据缺少创建信息时显示“未记录”，不根据最后编辑者推测。影像中已有的标注来源悬停查询继续显示体素标注作者，与标签创建者分开。
- 标签卡片使用与标签颜色一致的侧边浅深渐变色带、淡色背景与轮廓线；选中态加深侧边并保留独立背景，便于区分相邻卡片。
- “协作详情”保留并列意见和导出功能；错误、缓存异常、离线、任务加载失败与退出同步对话框仍可见。

影像浏览采用以下操作约定：

| 操作 | 行为 |
| --- | --- |
| 鼠标滚轮 | 在所在视图逐层浏览切片 |
| 中键拖动 | 平移该视图的影像 |
| 右键拖动 | 水平方向调整窗宽，垂直方向调整窗位 |
| Ctrl＋右键上下拖动 | 缩放该视图 |
| 点击视图底部的缩放百分比 | 同时重置该视图的缩放和平移 |
| 视图右上角按钮／双击切面标题／空格 | 最大化该切面，再次执行恢复多视图 |
| Esc | 恢复原多视图布局 |
| B／E／G | 切换画笔／橡皮擦／灰度分区 |
| Ctrl＋Z／Ctrl＋Y | 撤销／重做 |

平移、调窗和缩放属于浏览操作，不应生成掩膜笔画；只读账号仍可使用这些浏览操作。画笔、灰度轮廓和鼠标位置继续通过同一套平移、缩放坐标换算定位。协同编辑保留新版权限约束，包括只能删除自己的标注。

这些操作参考 OHIF、Mimics 等主流影像标注工具的使用习惯，并非对它们全部功能或快捷键的逐项复刻。界面中的“操作说明”提供本项目实际采用的约定。

切面术语与 [Materialise Mimics Core 官方教程](https://www.materialise.com/en/academy/healthcare/mimics-innovation-suite/video-tutorials/get-started-mimics-core)、[OHIF MPR 官方实现](https://docs.ohif.org/coverage/extensions/cornerstone/src/hps/mpr.ts) 使用的 Axial、Coronal、Sagittal 对应：轴位（横断位）、冠状位、矢状位。Mimics 官方教程同时说明空格最大化／恢复操作。I/J/K 是体素轴，不能直接当作标准解剖切面；本项目仍依据方向矩阵命名，对斜切或未定义方向显示原始轴提示。

## 数据说明

仓库不包含原始 CT、分割成果、账号数据库、本地缓存或测试账号凭据。`public/cases.json` 中的患者名称和描述均为明确标记的示例展示资料。

Java 平台使用独立的账号和任务数据库，不会自动将目录中的 CT 发布为任务。请用派活账号通过上传流程发布影像，再由标注小组认领。旧 Node 版昵称身份和成果迁移需要单独处理；切换数据目录时应保留原数据。

## 运行

需要 Node.js 24+、JDK 17+、Maven 3.9+。在仓库根目录构建前后端：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run build:server
```

本机启动示例使用 8794 端口，数据目录可按需配置：

```powershell
$env:HOST = '127.0.0.1'
$env:PORT = '8794'
$env:STATE_DIR = 'server-data/platform'
$env:DATASET_DIR = 'server-data/datasets'
java -jar backend/target/deepmark-server.jar
```

本机通过 `http://localhost:8794/` 使用。开发模式可在构建 Java 后执行 `npm.cmd run dev`。跨电脑登录按项目部署说明配置统一服务地址和 HTTPS；以上示例保持本机监听。
