# 青绿工作台与团队平台整合

本分支沿用原团队平台的登录、角色工作台与标注流程，将参考图中的青绿浅色工作台接入真实病例导航和实时协作。在线成员、标签创建者与协同成果由配套 Java 接口提供；完整功能需要使用相匹配的前后端版本。

## 保留与接入

- 视觉：青绿浅色工具面板、横向标注工具栏、深色影像区与实时协作抽屉；角色工作台保留病例列筛选及排序。
- 入口：使用新版 `AuthView` 登录和 `ConsoleView` 角色工作台；病例表格由 Console 提供真实任务数据。
- 标注：保留新版缩放、外围空气过滤、作者提示、协同增量、只读与作者权限。
- `CaseList.vue` 只负责展示；上传、组队、认领、完成和导出的权限判断仍由新版 Console 与 Java 后端负责。
- `public/cases.json` 仅补充可选展示资料，不能决定任务状态或访问权限。

## 平台页面样式

登录、注册、派活工作台、干活工作台、病例列表、任务详情与本地工作缓存窗口共用编辑器的青绿浅色视觉：DeepMark 文字品牌、白色页头、细边框面板、统一字体与按钮、轻量状态标签。输入焦点、错误、成功、空列表与禁用状态使用一致的配色。

窄屏时表单与面板按内容纵向排列，病例表格转为卡片行，任务按钮仍可直接操作；长病例名和小组名称允许换行。配色与布局调整保留现有登录、角色、小组、上传、认领、完成、只读和导出流程。

## 工作台设计与操作

工作台采用青绿强调色和浅色面板，影像区域保留深色背景。病例导航位于影像左侧，实时协作位于右侧，均默认折叠，可分别展开。

- 默认采用单幅视图，从轴位开始；可在病例导航中选择其他切面，也可通过横栏切换为“一张主视图＋两个辅助切面”或三列布局。
- 左侧病例导航展开后，可选择当前账号可访问的病例，使用上一／下一病例及上一／下一切片按钮，查看体素尺寸与间距。切换病例仍经过已有的待同步工作处理与权限检查。
- 每个切面右上角均有最大化／恢复按钮；双击切面标题或选中切面后按空格可切换最大化，Esc 恢复进入最大化之前的布局。切换时保持各切面的切片、缩放、平移和标注状态，画布双击不负责切换布局。
- 最大化时影像铺满左侧工具栏以外的整页区域，页头、协作栏与底部信息栏收起，切面标题、恢复按钮和翻层控件以浮层保留；恢复后原界面和协作信息重新显示。错误提示与退出对话框不因最大化而失效。
- 标签卡片不参与纵向压缩，使用自适应高度、较大的内边距与卡片间距；标签名和创建者均允许自然换行，长内容撑高当前卡片，多标签通过列表滚动查看。单击或双击名称均只选中标签，只有小铅笔按钮进入改名。编辑态使用与展示态同列宽的多行输入框，文字自动换行，边框随内容增加或缩回，创建者保持在编辑框下方。Enter／失焦提交，Esc 取消；视觉换行不改变名称数据，粘贴的实际换行在提交时规范为空格，中文输入法组词确认不会提前提交。
- 画笔、橡皮擦、阈值和灰度分区位于影像上方的横向工具栏，旁边提供撤销、重做与布局切换。先选择标签，再用左键执行当前工具；普通画笔编辑当前切片，阈值应用于整套影像。
- 左侧标签面板保留标签、画笔参数和影像显示设置，可通过导航栏展开或收起；窄屏默认收起。影像名称显示在页头和当前病例信息中。画笔和橡皮使用中心小圆点配合物理尺寸外圈的光标。
- 外围空气过滤始终开启，保留内部气腔与已有标注；旧缓存中的关闭设置不再恢复。“悬停显示灰度区域轮廓”及分区设置仅在“灰度分区”工具下显示，每次切入默认开启，其他工具下关闭并清除轮廓。
- 窗宽窗位可手动输入，也可选择肺窗（窗位 -600、窗宽 1500）、软组织（40、400）、骨窗（400、1800）和全范围预设。
- 右侧实时协作默认折叠为窄栏，可展开查看当前工程的在线成员、协作动态与同步状态。在线成员依据认证 WebSocket 连接、同一用户多标签去重，断线后不把缓存成员显示为在线。折叠时仍保留在线人数和同步摘要。
- 展开“协作详情与历史”可查看并列意见、导出本地副本及操作记录；详细历史通过“查看此版本”进入只读回放，再通过“返回实时编辑”退出回放。同步错误、离线与缓存异常在协作栏折叠或切面最大化时仍有提示，退出同步对话框保持可见。
- 标签行单独显示创建者，新增标签的创建者和时间由服务器记录并随快照、增量及导出保存；修改标签名或颜色不改变创建者。旧数据缺少创建信息时显示“未记录”，不根据最后编辑者推测。影像中已有的标注来源悬停查询继续显示体素标注作者，与标签创建者分开。
- 标签卡片使用与标签颜色一致的侧边色带、淡色背景与轮廓线；选中态加深侧边与背景，便于区分相邻卡片。
- 切面底部和工作台底部信息栏均可直接输入切片页码：输入时保留草稿，按 Enter 或失焦后跳转；Esc 恢复为当前页码。页码从 1 开始，整数越界时限制在 1 到总页数之间，空白或无效输入恢复为当前页码。底部信息栏控制当前激活的切面，两处页码随滚轮、滑块和切片按钮保持同步。

影像浏览采用以下操作约定：

| 操作 | 行为 |
| --- | --- |
| 鼠标滚轮 | 在所在视图逐层浏览切片 |
| 底部两处切片页码输入框 | 输入页码，Enter／失焦提交跳转，Esc 恢复；越界整数限制到影像范围 |
| 中键拖动 | 平移该视图的影像 |
| 右键拖动 | 水平方向调整窗宽，垂直方向调整窗位 |
| Ctrl＋右键上下拖动 | 缩放该视图 |
| 点击视图底部的缩放百分比 | 同时重置该视图的缩放和平移 |
| 横向工具栏的布局按钮 | 切换单幅、主辅或三列布局 |
| 视图右上角按钮／双击切面标题／空格 | 最大化该切面，再次执行恢复原布局 |
| Esc | 在页码框中恢复当前页码；其他位置关闭操作说明或恢复最大化前的布局 |
| B／E／G | 切换画笔／橡皮擦／灰度分区 |
| Ctrl＋Z／Ctrl＋Y | 撤销／重做 |

触屏设备会额外显示单指模式栏，默认“翻片”。“翻片”上下滑动逐层浏览，轻点标注可查看来源；“标注”按当前画笔、橡皮或灰度分区执行编辑；“平移”拖动影像；“调窗”左右调整窗宽、上下调整窗位。双指随时缩放并平移，增加第二指会取消尚未提交的本次笔画；一指离开后，剩余手指不会接着画，全部抬起后才能开始下一笔。手写笔可以直接标注。

灰度分区在触屏“标注”模式按住并拖动时显示预览，抬起后加入当前标签；增加第二指或收到系统取消事件会取消选区。只读时“标注”不可选，翻片、平移、调窗和双指缩放仍可用。触屏控件加大点击范围，窄屏标签、病例和协作面板覆盖展开，可点击遮罩收起；横屏和多视图可以纵向滚动，最大化仍保留模式栏。

翻片、页码跳转、布局切换、平移、调窗和缩放属于浏览操作，不应生成掩膜笔画；只读账号仍可使用这些浏览操作。画笔、灰度轮廓和鼠标位置继续通过同一套平移、缩放坐标换算定位。协同编辑保留新版权限约束，包括只能删除自己的标注。

这些操作参考 OHIF、Mimics 等主流影像标注工具的使用习惯，并非对它们全部功能或快捷键的逐项复刻。界面中的“操作说明”提供本项目实际采用的约定。

## 上传与下载进度

上传影像、进入病例的影像下载、工作台与编辑器的成果 ZIP 下载共用进度卡。显示实际已传输字节数，响应提供可比较总长度时显示百分比；未知长度或透明解压响应保持持续进度，不估算百分比。传输过程中可以取消并重试，取消病例下载会保留当前影像与协作。

上传体发送完成后，进度卡继续提示服务器校验与发布，等待成功或错误结果；此阶段不提供会造成发布结果不确定的取消按钮。打开影像时依次提示解析、缓存与团队标注加载，缓存命中会跳过下载。成果接收完成后交由浏览器保存，浏览器文件保存过程不计入网络进度。

切面术语与 [Materialise Mimics Core 官方教程](https://www.materialise.com/en/academy/healthcare/mimics-innovation-suite/video-tutorials/get-started-mimics-core)、[OHIF MPR 官方实现](https://docs.ohif.org/coverage/extensions/cornerstone/src/hps/mpr.ts) 使用的 Axial、Coronal、Sagittal 对应：轴位（横断位）、冠状位、矢状位。Mimics 官方教程同时说明空格最大化／恢复操作。I/J/K 是体素轴，不能直接当作标准解剖切面；本项目仍依据方向矩阵命名，对斜切或未定义方向显示原始轴提示。

## 数据说明

仓库不包含原始 CT、分割成果、账号数据库、本地缓存或测试账号凭据。`public/cases.json` 中的患者名称和描述均为明确标记的示例展示资料。

Java 平台使用独立的账号和任务数据库，不会自动将目录中的 CT 发布为任务。请用派活账号通过上传流程发布影像，再由标注小组认领。旧 Node 版昵称身份和成果迁移需要单独处理；切换数据目录时应保留原数据。

## 运行

需要 Node.js 24+、JDK 17+、Maven 3.9+。在仓库根目录构建前后端：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run build:server
```

本机启动示例使用 8794 端口，数据目录可按需配置：

```powershell
$env:HOST = '127.0.0.1'
$env:PORT = '8794'
$env:STATE_DIR = 'server-data/platform'
$env:DATASET_DIR = 'server-data/datasets'
java -jar backend/target/deepmark-server.jar
```

本机通过 `http://localhost:8794/` 使用。开发模式可在构建 Java 后执行 `npm.cmd run dev`。跨电脑登录按项目部署说明配置统一服务地址和 HTTPS；以上示例保持本机监听。
