# 外围视觉与动效迁移

本轮在已发布的 `25b9efd` 上，参考 `deepmark-front-visual-refresh` 迁移用户批准的顶部与左侧视觉。登录、任务及病例列表页面与参考目录逐字一致，没有重复修改。参考项目较旧，未复制其控制器、API、原生视口或整个样式表。

## 迁移范围

- 顶部协同栏、品牌与项目标题、原有文件操作、编号工作流页签、底部状态栏。
- 左侧对象页签、平铺 Mask/Part 列表、选中条、隐藏状态提示、属性与测量/RP 列表、窗宽窗位及原有预设按钮。
- 悬停下划线、选中条过渡及外围浮层的轻量进入动画；系统要求减少动效时停用。

新增样式由 `src/workbench/chromeRefresh.css` 及其导入的 `topbarRefresh.css`、`objectPanelRefresh.css` 提供，`WorkbenchHost.vue` 仅增加样式导入。变量与规则限定在批准的外围容器，不设置到编辑器根节点；顶部外部行高、左侧布局轨道宽度保持原样。浮层使用独立 `translate`，避免覆盖错误提示已有的水平居中变换。

用户明确保留的影像区（含普通/MPR、三维预览及其控件）与最右侧工具栏不套用新视觉；未修改标注算法、画笔、权限、协同协议或按钮事件，也未增减操作按钮。原深色、居中的“返回实时成果”、历史侧栏隐藏、他人网格、单视图全屏倍率及 500ms 静止悬停策略均保留。

## 验证

- 125 项现有 Node 测试、Vue 类型检查、生产构建通过；83 个原生文件和 12 个交互函数的基线校验通过。
- 在独立合成任务的同一状态、1280×720 浏览器中，记录并比较影像区 95 个与右侧工具栏 56 个元素的矩形、背景、颜色、边框、字体、布局属性，151 个元素均无差异。
- 历史回看按钮仍为 `rgb(8,105,93)` 底色、白字，中心与页面中心一致；返回实时后原工具栏正常恢复。
- 1000×720 响应检查中，六个顶部原有文件操作全部位于视口内，页面宽度没有溢出；检查后清除临时视口设置。
- 单视图全屏时显示一个倍率控件，Esc 后常态恢复零个；未更改真实 bone 标注。

本轮截图和对比记录仅保存在被忽略的 `artifacts/visual-refresh/`。参考目录原样保留。后续导航性能修复完成后，按用户明确要求一同发布；性能对照见 `slice-navigation-performance.md`。
