# 医学分割标注网页版（首版）

## 启动

开发电脑需要 Node.js 22.12+ 或 Node.js 24。最终用户只需要新版 Edge/Chrome 浏览器。

在下载或克隆后的项目根目录执行：

```powershell
npm install
npm run dev
```

打开终端显示的本地网址，通常是 http://127.0.0.1:5173 。

```powershell
npm test
npm run build
```

部署时将 `dist` 目录托管为静态网站即可，用户不用安装 Node.js 或 Slicer。gzip 解压需要支持 DecompressionStream 的浏览器。

## 当前功能

- 三维灰度 NIfTI-1 `.nii` / `.nii.gz` 读取，支持常见整数、浮点数据及大小端。
- 三个原始体素切面、空间比例、切片滑条、滚轮切片、定位工具联动。
- 窗宽窗位、多标签、颜色与名称设置、显示隐藏、透明度。
- 单切片圆形画笔、只擦除当前标签的橡皮擦、撤销重做（最多 80 步，历史目标上限 64 MB，单笔超限时保留该笔）。
- 灰度阈值分割：三切面预览、上下限数值与滑块、整套三维影像应用、单步撤销重做；预览不会改动或导出标注。
- 导出 uint16 分割 NIfTI，保持原影像尺寸、qform/sform 和坐标网格；可重新导入同空间的分割文件。
- 单独导出标签名称与颜色 JSON 说明。NIfTI 本身不携带这份界面配色；重新导入分割时按标签值生成默认名称和颜色。
- 合成练习影像，非患者影像。

## 操作

1. 选择影像，或点击“先用合成影像体验”。
2. 选择或新增标签；B 切画笔，E 切橡皮擦，V 切定位。
3. 在任意切面拖动画笔；滚轮或滑条切片。画笔会覆盖其他标签，橡皮擦仅擦除当前标签。
4. Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。
5. 导出标注，并按需导出标签说明。继续工作时先打开原影像，再导入已有分割。

阈值工具：选择当前标签，点击“阈值”，调整最小/最大灰度（包含上下限），检查三个切面的预览，再点击“应用阈值分割”。使用 NIfTI 灰度缩放后的数值，不受窗宽窗位影响。应用会按范围替换当前标签，范围内覆盖其他标签，范围外仅清除当前标签、保留其他标签。没有符合范围的体素时当前标签将被清空，可撤销。应用后返回画笔工具，允许手动修正。此行为参考 Slicer Threshold 的 `ThresholdBetween` 与 `ModificationModeSet`，未包含其自动阈值计算或编辑遮罩选项。

## 范围和实现

React + TypeScript + Vite；此首版采用自有 Canvas 切片与体素画笔，尚未接入 Cornerstone3D，也未直接移植 Slicer 的 Qt/VTK 运行代码。参考项目为相邻 `Slicer-main/Slicer-main` 的分割编辑器结构。Slicer 原始文件没有修改。

影像不上传；文件解析、显示和标注均在本机浏览器内执行。当前不包含 DICOM、NIfTI-2、4D、多通道、AI 分割、种子生长、3D 渲染、项目自动保存或协作。

对轴对齐且有空间定义的影像显示解剖切面与方位。斜切或缺少方向定义的影像按原始 I/J/K 显示，界面明确提示；没有执行标准解剖平面的重采样。空间单位为米或微米时转换到毫米供显示与画笔计算；缺少单位时标注为“影像单位”。

体素上限为 128×1024×1024。浏览器实际可用容量取决于内存；大文件读取、解压和初次解析可能短暂阻塞界面，此版本还没有实现分块或 Worker。刷新前请导出；当前不自动恢复标注。作为原型使用，需要以实际影像和 Slicer 验证空间对应关系。
