# 医学分割标注网页版（首版）

## 启动

开发与服务器需要 Node.js 24+（使用内置 SQLite 和 TypeScript 类型擦除）。最终用户只需要新版 Edge/Chrome 浏览器。

在下载或克隆后的项目根目录执行：

```powershell
npm install
npm run dev
```

打开终端显示的本地网址，通常是 http://127.0.0.1:5173 。

```powershell
npm test
npm run build
```

`npm run dev` 同时启动网页（通常为 5173 端口）和数据集 API（默认 8787 端口），网页会自动转发 API 请求。用户不用安装 Node.js 或 Slicer。gzip 解压需要支持 DecompressionStream 的浏览器。

## 服务器数据集

网页顶部“服务器数据集”或首页“从服务器选择数据集”可以打开数据集列表，按文件名/分类搜索，查看大小和更新时间。

- **下载并标注**：把选中的影像下载到浏览器，显示下载进度，解析后进入三切面标注；不要求用户先保存文件再重新导入。
- **仅下载原文件**：直接保存原始 `.nii` / `.nii.gz`，不替换正在编辑的影像。
- **刷新列表**：发现管理员刚添加或删除的文件，无需重启服务。

管理员把影像放入 `server-data/datasets/`，可用子文件夹分类。实际数据文件均被 Git 忽略，不会提交到 GitHub。此目录和应用源码不会被作为静态网页文件公开。列表和下载接口只提供目录内的 NIfTI 文件，忽略隐藏文件与符号链接；支持 HTTP Range 与 HEAD。

尚无真实数据时，可生成一份合成练习影像：

```powershell
npm run sample-data
```

生产部署时在服务器运行：

```powershell
npm ci
npm run build
npm start
```

打开 `http://127.0.0.1:8787`，同一 Node.js 服务会提供 `dist` 网页和数据集 API。远程访问时可在前方配置 HTTPS 反向代理；需要直接监听网络接口时设置 `HOST=0.0.0.0`，端口通过 `PORT` 配置。

数据可以存放在另一块硬盘或挂载目录，通过环境变量指定，例如 PowerShell：

```powershell
$env:DATASET_DIR = 'D:\medical-datasets'
npm start
```

开发时 API 端口可通过 `API_PORT` 修改。若只静态托管 `dist`，仍需单独部署 Node.js 服务并反向代理 `/api`，包括 `/api/collaboration/socket` 的 WebSocket 升级；GitHub 仓库本身不会运行此服务。

## 多人实时协同

1. 每个人从服务器打开同一份数据集，输入各自的协同昵称，点击“加入实时协同”。所有成员权限相同，人工协调分工，不设任务锁。
2. 本机立即绘制，笔画结束后上传体素增量。事务保存确认后显示“已保存到服务器”，其他成员收到 WebSocket 通知后自动更新视图。
3. 不冲突的修改直接合并；同一体素的预期旧值与服务器不一致时，保留现有结果并新建冲突版本。通过“查看版本”切换结果。后续编辑同步到所有现存版本，未被本次操作修改的位置保留差异。同色画笔重画也会同步。
4. “工作记录”显示作者、时间、类型和版本。历史查看只读，不回退其他人当前的工作；点击“返回实时编辑”继续。
5. 协同导出从服务器读取选定分支与版本，文件名区分版本。有未确认操作时暂停导出，避免遗漏工作。

服务器以 SQLite WAL 事务保存分支快照和压缩操作历史，默认目录 `server-data/collaboration/` 已被 Git 忽略；可通过 `STATE_DIR` 指定持久磁盘。备份应包含此目录及原始影像。影像内容改变后会创建另一工程，避免错误复用旧标注。

当前是面向可信团队的昵称会话，人员 ID 和 HttpOnly Cookie 由服务器签发，昵称不是核实后的账号。同一浏览器可恢复身份、工作与历史；换设备或清除 Cookie 会产生新身份，但不删除原记录。正式公网使用仍需团队账号认证。HTTPS 部署可设置 `COOKIE_SECURE=1`。

未确认操作先写入 IndexedDB，再按唯一操作 ID 提交；断网时明确显示未确认，重连自动重试。刷新后重新加入同一工程也能恢复本浏览器的待提交队列。只有服务器确认的工作才显示为已保存。

当前同步笔画结束或阈值应用后的体素增量，不是逐鼠标帧同步。单次编码上限 32 MB（约 419 万个体素记录），过大时恢复到操作前并提示缩小范围。刷新使用完整分支压缩快照，尚未对大影像、多分支、大并发压测；适用于小团队功能验证。协同中暂不开放整份外部分割覆盖导入。Undo/Redo 栈限本次浏览器会话，跨会话历史可只读查看。

## 当前功能

- 三维灰度 NIfTI-1 `.nii` / `.nii.gz` 读取，支持常见整数、浮点数据及大小端。
- 三个原始体素切面、空间比例、切片滑条、滚轮切片、定位工具联动。
- 窗宽窗位、多标签、颜色与名称设置、显示隐藏、透明度。
- 单切片圆形画笔、只擦除当前标签的橡皮擦、撤销重做（最多 80 步，历史目标上限 64 MB，单笔超限时保留该笔）。
- 灰度阈值分割：三切面预览、上下限数值与滑块、整套三维影像应用、单步撤销重做；预览不会改动或导出标注。
- 导出 uint16 分割 NIfTI，保持原影像尺寸、qform/sform 和坐标网格；可重新导入同空间的分割文件。
- 单独导出标签名称与颜色 JSON 说明。NIfTI 本身不携带这份界面配色；重新导入分割时按标签值生成默认名称和颜色。
- 合成练习影像，非患者影像。
- 服务器数据集列表、搜索、原文件下载、下载进度、直接打开标注；服务器端通过目录管理待标注数据。
- Vue 3 前端；多人同权协同、冲突版本保留、后续编辑同步多版、服务端自动保存、断线队列与历史查看。

## 操作

1. 从“服务器数据集”下载并打开影像，选择本地影像，或点击“先用合成影像体验”。
2. 选择或新增标签；B 切画笔，E 切橡皮擦，V 切定位。
3. 在任意切面拖动画笔；滚轮或滑条切片。画笔会覆盖其他标签，橡皮擦仅擦除当前标签。
4. Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。
5. 导出标注，并按需导出标签说明。继续工作时先打开原影像，再导入已有分割。

阈值工具：选择当前标签，点击“阈值”，调整最小/最大灰度（包含上下限），检查三个切面的预览，再点击“应用阈值分割”。使用 NIfTI 灰度缩放后的数值，不受窗宽窗位影响。应用会按范围替换当前标签，范围内覆盖其他标签，范围外仅清除当前标签、保留其他标签。没有符合范围的体素时当前标签将被清空，可撤销。应用后返回画笔工具，允许手动修正。此行为参考 Slicer Threshold 的 `ThresholdBetween` 与 `ModificationModeSet`，未包含其自动阈值计算或编辑遮罩选项。

## 范围和实现

Vue 3 + TypeScript + Vite + Node.js + WebSocket + SQLite，采用单文件组件、Composition API 和 Canvas 体素切片。大体积数组使用 shallowRef 避免逐体素响应式开销。尚未接入 Cornerstone3D，也未直接移植 Slicer 的 Qt/VTK 运行代码；参考相邻 `Slicer-main/Slicer-main` 的分割编辑器结构，原始源码没有修改。

本地单人模式不上传影像或标注。加入协同后，原影像来自服务器，编辑操作和标签设置会传回服务器保存共享。当前不包含 DICOM、NIfTI-2、4D、多通道、AI 分割、种子生长或 3D 渲染。

对轴对齐且有空间定义的影像显示解剖切面与方位。斜切或缺少方向定义的影像按原始 I/J/K 显示，界面明确提示；没有执行标准解剖平面的重采样。空间单位为米或微米时转换到毫米供显示与画笔计算；缺少单位时标注为“影像单位”。

体素上限为 128×1024×1024。浏览器实际容量取决于内存；大文件解析可能短暂阻塞，此版本还未使用分块或 Worker。本地单人模式刷新前请导出；协同模式请等待保存确认。作为原型使用，仍需以实际影像和 Slicer 验证空间对应关系。
